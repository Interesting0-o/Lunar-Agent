### Layer 7 — 对抗式双Agent耦合检验 (`test_adversarial_engine.py`) ★新增

核心思路：将用户替换为另一个 Agent 实例，形成 A ↔ B 闭环耦合系统。移除 LLM 和感知节点，用 `Surface → Stimuli` 直接映射代替，使两个状态引擎互相驱动，可低成本运行成千上万轮。

**架构**：
```
Agent A (状态引擎)                    Agent B (状态引擎)
  internal_A, rel_A, traits_A          internal_B, rel_B, traits_B
       │                                     │
       ▼ surface_A                           ▼ surface_B
  ┌──────────────┐                    ┌──────────────┐
  │ Surface→Stim │ ── stimuli_B ──▶   │ State Engine │
  │   Mapping    │                    │   update_all │
  └──────────────┘                    └──────────────┘
       ▲                                     │
       │         ┌──────────────┐            │ surface_B
       │         │ State Engine │ ◀── stimuli_A ──┐
       └──────── │   update_all │    ┌──────────────┐
                 └──────────────┘    │ Surface→Stim │
                                     │   Mapping    │
                                     └──────────────┘
```

## 四、发现的关键问题

### 4.1 `soft_clamp` 非单调性 ⚠️ 设计特征

**现象**：x 越过 `[0, 1]` 边界时产生"惩罚谷"——输出先下探再渐近回升。在 `x ∈ [1.0, 1.1]` 区间违反严格单调性。

**原因**：tanh 过渡带公式 `high - transition × tanh((x-high)/transition)` 使刚跨越边界的值被"惩罚"到 `high - transition` 附近。

**影响**：不能用于需要严格单调的场景（概率校准）。在状态引擎中可能产生副作用——当 `inner_stimuli > 1.0` 被压制后可能略低于 `outer_stimuli`。

**状态**：已验证并文档化，暂不修改（属于设计取舍）。

### 4.2 `REL_STATE_COUPLING_A` 原始谱半径 > 1.0 ⚠️ 设计发现

**现象**：关系耦合矩阵原始 `ρ = 1.0063 ≥ 0.95`，触发谱归一化（缩放系数 0.9441）。

**影响**：对角线从设计的 0.90 降为实际的 0.85。关系状态惯性略低于预期。

**建议**：重新审视关系耦合矩阵的权重设置，或接受归一化后的值作为新的设计基线。

### 4.3 耦合效应压制刺激效应 ⚠️ 参数平衡

**现象**：α（耦合速率）≈ 0.291，β（刺激接受速率）≈ 0.10。耦合矩阵的交叉项在某些维度上比外部刺激的影响更大。

**具体案例**：
- `ST_ABANDONMENT` 刺激应增加 `I_LONELINESS`（B 矩阵正向），但耦合项 `I_ENERGY → I_LONELINESS = -0.05` 反而将孤独感拉低
- `ST_VALIDATION` 刺激应增加 `I_ENERGY`，但耦合惯性（α × 对角偏离）使精力不升反降

**建议**：考虑增大 β 或减小 α，或对耦合矩阵交叉项进行衰减。

### 4.4 `inner ≥ outer` 不变式在高刺激下打破 ⚠️ 边界效应

**现象**：当 hyper 很高 + 刺激接近 1.0 时，inner > 1.0 被 soft_clamp 惩罚谷压制，可能略低于 outer。

**影响范围**：仅在高强度刺激（> 0.7）时出现，中等刺激下不变式始终成立。最大逆差 < 0.05。

### 4.5 `_sigmoid(37+)` 饱和为精确 1.0 ℹ️ 浮点精度

float64 精度极限，非 bug。`σ(35) = 1 - 6.66e-16`，`σ(37) = 1.0`。

### 4.6 α 永远大于 β — 耦合效应全面压制刺激 ⚠️ 高

**现象**：在 20,000 组随机人格/关系参数下，α/β 比率始终 ≥ 1.51，α > β 的概率为 100%。

| 参数 | μ | σ | [min, max] |
|------|---|---|-----------|
| α (耦合速率) | 0.279 | 0.047 | [0.151, 0.350] |
| β (刺激接受) | 0.100 | 0.000 | [0.100, 0.100] |
| α/β 比率 | 2.79 | 0.47 | [1.51, 3.50] |

**影响**：无论什么人格/关系状态，耦合惯性永远比刺激接受强 1.5–3.5 倍。对话的影响被结构性地压制。

**根因**：β 在不考虑防御剖面时为固定 0.10，即使在防御剖面作用下也只能在 [0.01, 0.35] 范围。而 α 基线在 [0.15, 0.35]。

**建议**：将 β 的基线从 0.10 提高到 0.15–0.20，或降低 α 的基线。

### 4.7 耦合矩阵系统性偏压低 ⚠️ 高

**现象**：在默认内部状态下（高能量 0.7、高社交电量 0.6），`A@h - h` 对**全部 8 个维度都是负值**。

| 维度 | 当前值 | 耦合效应 | 方向 |
|------|--------|---------|------|
| energy | 0.7000 | -0.1050 | ↓拉低 |
| stress | 0.2000 | -0.0400 | ↓拉低 |
| loneliness | 0.3000 | -0.0640 | ↓拉低 |
| social_battery | 0.6000 | -0.0900 | ↓拉低 |
| mental_fatigue | 0.1500 | -0.0625 | ↓拉低 |

**影响**：耦合矩阵的惯性效应（对角线 0.85）使所有高于 0 的维度被系统性往下拉。对话的正面影响被抵消。

**根因**：对角线 0.85 对高值维度产生 `0.85*h - h = -0.15*h` 的负效应，而交叉项的正贡献不足以补偿。

### 4.8 往返迟滞 — 刺激方向不对称 ⚠️ 高

**现象**：先施加 50 轮正向刺激（认可+亲密），再施加 50 轮反向刺激（冲突+抛弃），期望回到起点附近。实际结果：

| 阶段 | 与起点距离 |
|------|-----------|
| 起点 | 0.000 |
| 正向 50 轮后 | 0.531 |
| 反向 50 轮后 | **0.975** |

反向刺激不仅没有"修复"正向刺激的效应，反而把状态推得更远了。

**影响**：系统的正向和负向响应不对称。用户先夸奖再冲突，比一直冲突更糟糕——系统没有"抵消"机制。

### 4.9 防御剖面无法达到极端值 ⚠️ 中

**现象**：即使用 30,000 组极端人格/状态参数（Beta(0.2, 0.2) 两极分布），deact 和 hyper 也都卡在狭窄区间内：

| 指标 | [min, max] |
|------|-----------|
| deact mean | [0.335, 0.590] |
| hyper mean | [0.338, 0.619] |
| 双零剖面 (both < 0.05) | 0.0% |
| 双一剖面 (both > 0.90) | 0.0% |
| 铁壁模式 (高deact+低hyper) | 0.0% |
| 玻璃心模式 (低deact+高hyper) | 0.0% |

**影响**：Bowlby 理论中的 4 种防御模式（铁壁、玻璃心、真淡定、纸墙）无法通过参数调出来。sigmoid 的阈值（deact-0.48, hyper-0.50）配合当前权重，使防御剖面永远卡在中等范围。

**建议**：调整 sigmoid 偏移量，或增加权重系数使剖面能覆盖 [0, 1] 全范围。

### 4.10 耦合矩阵存在震荡模式 ⚠️ 中

**现象**：特征值分解发现复特征值：

| 矩阵 | 复特征值数量 | 复特征值 | 主导实特征值 |
|------|------------|---------|-------------|
| STATE_COUPLING_A | 2 | 0.8007 ± 0.0854i | **0.9486** |
| REL_STATE_COUPLING_A | 4 | 0.8050 ± 0.0531i, 0.8615 ± 0.0222i | **0.9500** |

**影响**：
- 复特征值 → 某些维度组合会产生阻尼震荡（先升后降再升…）
- 主导特征值 0.95 ≈ 1.0 → 存在极慢衰减模式，某些暂态需要 > 100 轮才能消失

### 4.11 人格特质敏感度过低 ⚠️ 中

**现象**：±0.1 的特质变化（如 anxiety 从 0.5→0.6），仅产生约 0.001–0.005 的内部状态 L2 变化。

**影响**：不同人格的角色在行为上几乎无法区分。状态引擎对特质参数的依赖太弱。

**根因**：特质主要通过 setpoint 和速率参数间接影响状态，而单轮变化太小。

### 4.12 维度响应不均 — `longing` 近乎冻结 ⚠️ 低

**现象**：100,000 组极端刺激下，`longing` 单轮最大绝对变化仅 0.0189（其他维度 0.03–0.09）。`romantic_tension` 单轮最大变化仅 0.0046。

**影响**：思念和浪漫张力这两个关键浪漫维度几乎不受对话影响。

### 4.13 表面维度饱和 ⚠️ 低

**现象**：50,000 组随机参数中：
- `sharpness` 有 0.80% 触顶（≥ 0.99）
- `vulnerability` 有 1.26% 触底（≤ 0.01）

**影响**：在某些参数组合下表面维度完全退化到边界值。

### 5.1 稳态系统性偏离 setpoint — `loneliness` 和 `social_battery` 崩溃 🔴 严重

**现象**：在零刺激条件下，内部状态不收敛到 `compute_setpoint()` 的目标值，而是收敛到显著偏低的"影子稳态"。

| 维度 | setpoint | 真实稳态 | 偏移 | 200组中偏离>0.2的比例 |
|------|----------|---------|------|:--------:|
| energy | 0.70 | 0.47 | **-0.22** | 6% |
| loneliness | 0.30 | 0.18 | **-0.12** | **93%** |
| social_battery | 0.60 | 0.41 | **-0.19** | **92%** |
| mental_fatigue | 0.15 | 0.04 | **-0.10** | 24% |

**根因**：残差动力学在零刺激时的真实平衡点是：
```
h_eq = γ · ((α+γ)·I - α·A)⁻¹ @ setpoint
```
而非 `setpoint`。耦合矩阵对角惯性 0.85 产生 `-0.15×h` 的自抑制力，`α/γ = 3.16x` 使下拉力远超恢复力。

`loneliness` 和 `social_battery` 在 STATE_COUPLING_A 中**完全没有跨维度耦合入边**，是最严重的受害者：
- `loneliness`：唯一入边是 `stress → loneliness = +0.08`，不足以补偿下拉
- `social_battery`：**零入边**，只能靠自抑制+恢复力

**验证**：理论稳态 `loneliness_eq = 0.30×0.092/(0.15×0.291+0.092) = 0.180` — 完美匹配观测值。`social_battery_eq = 0.60×0.092/(0.15×0.291+0.092) = 0.404` — 同样完美匹配。

**修复**：提高 `γ_base` 从 0.08 到 0.15（使 α/γ 从 3.2x 降到 1.9x），或给这两个维度增加跨维度耦合入边。

### 5.2 `noisy_perception` 确定性崩溃模式 🔴 严重

**现象**：当使用 DEFAULT_TRAITS + `tanh` 非线性映射 + 噪声(0.02~0.08) 时，系统**确定性地**崩溃到以下状态：

```
social_battery: 0.600 → 0.077  (-87%)  ← 几乎归零
stress:         0.220 → 0.586  (+166%) ← 飙升
irritation:     0.100 → 0.461  (+361%) ← 暴涨
mental_fatigue: 0.145 → 0.464  (+213%)
```

Top 10 最严重异常案例中 **9/10** 是此场景，且结果完全一致（相同的 DEFAULT_TRAITS 产生相同的崩溃轨迹）。

**根因**：tanh 非线性改变了刺激分布的中心和方差 → 负面维度(conflict/abandonment)的刺激持续偏高 → 累积效应通过 Surface→Stimuli 反馈回路放大 → 不可逆崩溃。

**修复**：在 `SurfaceToStimuliMapping` 的 tanh 模式下增加均值校正，或对 stimuli 输出做归一化。

### 5.3 Surface 闭环增益 > 1.0 — 弱放大特性 🟡 中等

**现象**：在 200 组试验中，**98%** 的 Surface→Stimuli→Surface 闭环增益 > 1.0，均值 1.14x。

**影响**：耦合系统整体呈**弱放大**特性。信号不会自行衰减，而是被反馈回路维持/放大。这解释了为何负面刺激会持续累积。

**根因**：默认耦合矩阵 W (7×7) 的谱范数 > 1.0。映射后的 stimuli 在 soft_clamp 压制下仍保持一定强度。

### 5.4 特质风险因素确认 🟡 中等

通过 200 组试验的高异常组(>10 异常, n=16) vs 干净组(0 异常, n=28) 对比：

| 特质 | 高异常均值 | 干净均值 | Δ | 解读 |
|------|:------:|:-----:|:---:|------|
| attachment_avoidance | 0.22 | 0.41 | **-0.18** | 回避是**保护因素** |
| attachment_anxiety | 0.55 | 0.40 | **+0.15** | 焦虑是**风险因素** |
| emotional_stability | 0.49 | 0.61 | **-0.11** | 低稳定是**风险因素** |
| pride | 0.64 | 0.54 | +0.10 | 高自尊略增风险 |

**结论**：低回避 + 高焦虑 + 低稳定 = 最危险的特质组合。

### 5.5 发散异常按维度分布 🟡 中等

200 组试验中 841 个发散异常的维度分布：

| 维度 | 高严重度 | 中等 | 总 | 偏离方向 |
|------|:-----:|:---:|:---:|:------:|
| social_battery | 106 | 48 | 154 | 全部偏低 |
| loneliness | 0 | 141 | 141 | 全部偏低 |
| familiarity | 87 | 11 | 98 | 全部偏高 |
| stress | 2 | 91 | 93 | 偏高为主 |
| irritation | 5 | 86 | 91 | 偏高为主 |
| dependency | 8 | 92 | 100 | 全部偏高 |

关键模式：
- **"低电量 + 低孤独"**：social_battery↓ + loneliness↓ → 角色既不想社交也不觉得孤独，陷入"冷漠麻木"状态
- **"高压力 + 高依赖"**：stress↑ + dependency↑ → 角色又焦虑又粘人

### 5.6 焦虑型 vs 回避型耦合验证 🟢 通过

焦虑型（高依恋焦虑 0.85 + 低回避 0.10）vs 回避型（高回避 0.80 + 低焦虑 0.15）的耦合运行显示：

- 焦虑型的不安全感均值 (0.137) > 回避型 (0.054) ✓ 符合预期
- 焦虑型的 loneliness 在耦合中降至 0.002（接近归零），因为回避型的冷淡表面被映射为 abandonment stimulus
- 回避型的 affection (0.38) < 焦虑型的 affection (0.51) ✓ 符合预期

### 5.7 单次大冲击恢复验证 🟢 通过

注入全维度 0.95 强度冲击后 200 轮，stress 从冲击时的峰值显著降低，最后 100 轮均值回归到 setpoint ± 0.3 范围。系统具备冲击恢复能力。

### 5.8 10000 轮长期漂移检测 🟢 通过

对称耦合 10000 轮后：所有维度尾均值在 setpoint ± 0.3 范围内，方差随步数增加而下降（系统趋于稳定），无 NaN/Inf，无边界违规。
