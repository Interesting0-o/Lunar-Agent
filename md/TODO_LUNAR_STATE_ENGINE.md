# Lunar State Engine — 改进待办与诊断报告

> 本文档收集 Lunar 项目状态引擎（`state_engine.py` 及其配套模块）的所有待解决问题、改进方向与学术参考来源。
> 状态：调研完成，解决方案待定（不着急出方案，先把问题清单固定下来）。

---

## 一、严重问题（🔴 影响核心功能）

### 🔴 问题 1：特质永远不变，角色"长不大"

- **问题代码**：`state.py:79-89` + `default_state.py:23-34`
- **症状**：`T_SENSITIVITY / T_ATTACHMENT_ANXIETY` 等 10 维特质在整个生命周期内不更新
- **后果**：
  - 真人相处 6 个月，`attachment_anxiety` 应从 0.7 降到 0.4（安全感建立）
  - 真人经历创伤后，`anger_reactivity` 会升高
  - Lunar 的角色永远停留在初始特质——玩 100 轮和 1 轮性格没差别
- **学术参考**：
  - Bowlby 依恋理论："内化工作模型"会随"一致关怀"逐步修正
  - McAdams 人生叙事理论：人格是分层的（特质 → 角色 → 人生故事），Lunar 只做了第 1 层
- **状态**：调研完成

### 🔴 问题 2：刺激向量只有 7 类信号，关键情绪类别缺失

- **问题代码**：`state.py:147-155`
- **现有 7 维**：`ST_ABANDONMENT / VALIDATION / CLOSENESS / CONFLICT / DEPENDENCY / TEASING / EMOTIONAL_WEIGHT`
- **缺失维度**：
  - `ST_ANTICIPATION`：期待/盼望（对方即将出现/有好事）
  - `ST_GUILT`：内疚/自责（"我伤害了对方"）
  - `ST_DISAPPOINTMENT`：失望（与 abandonment 不同，是"期望落空"）
  - `ST_GRATITUDE`：感激（长期关系中尤其关键）
  - `ST_CURIOSITY`：好奇/兴趣（驱动对话的内在动力）
- **学术参考**：
  - Plutchik 情感轮盘：8 种基本情绪
  - Ekman 6 种基本情绪：快乐/悲伤/恐惧/愤怒/惊讶/厌恶
  - Lunar 的 7 维偏重"关系性"刺激，缺少"自我相关"刺激
- **状态**：调研完成

### 🔴 问题 3：无"记忆"机制，角色"金鱼脑"

- **问题代码**：`agent.py` / `state_engine.py` 全局
- **症状**：
  - InternalState 是"状态"（8 维实时），不是"记忆"
  - 真人伴侣会记住"上次你答应过周末一起做饭"——Lunar 完全没有
  - 用户说"你记得我们第一次聊天吗？"，角色无法回答具体事件
- **学术参考**：
  - Atkinson-Shiffrin 记忆模型：感觉记忆 → 短时记忆 → 长时记忆
  - Ebbinghaus 遗忘曲线：记忆随时间指数衰减
  - 情境依赖记忆：特定情绪状态下的记忆更易被同状态触发
- **状态**：调研完成

### 🔴 问题 4：无"目标/意图"系统，角色"无欲无求"

- **问题代码**：全项目没有
- **症状**：
  - 真人伴侣会有"想和 ta 一起看电影"的目标
  - 真人会有"想保护 ta""想让 ta 开心"的意图
  - 真人会有"想确认 ta 爱不爱我"的反复追问
  - **Lunar 的角色完全被动响应**，没有任何"想做某事"的内部驱动
- **学术参考**：
  - BDI 模型（Beliefs-Desires-Intentions）：经典 agent 架构
  - Schema Theory：人脑用"图式"驱动行为（约会图式、亲密图式）
  - Goal-Directed Behavior：行为由目标驱动而非纯刺激响应
- **状态**：调研完成

## 二、中等问题（🟡 影响真实感）

### 🟡 问题 5：表面表达只有 7 维，无法表达细腻情感

- **问题代码**：`state.py:58-65`
- **现有 7 维**：`S_EXPRESSIVENESS / WARMTH / SHARPNESS / SOFTNESS / ENTHUSIASM / RESTRAINT / VULNERABILITY`
- **症状**：
  - 真人表情有 40+ 种可识别情绪（基本情绪 + 微表情）
  - 7 维过于粗粒度——"温柔地笑"和"害羞地笑"无法区分
  - 缺少"playfulness（俏皮）""defiance（倔强）""longing（渴望）""contempt（轻蔑）"
- **学术参考**：
  - FACS（Facial Action Coding System）：44 个动作单元
  - Russell's Circumplex Model：2 维（valence × arousal），理论上连续
  - 当前实现是**离散化**版本，有信息损失
- **状态**：调研完成

### 🟡 问题 6：无"动作/行为"系统，角色"只说不做"

- **问题代码**：`project_surface` 之后直接给 LLM
- **症状**：
  - 真人伴侣会有"我给你倒杯水""我把电视关了"等**主动行为**
  - Lunar 的角色**只能说话**，没有任何"做事"能力
  - 比如"ta 帮你整理房间""ta 给你买早餐"——目前无法建模
- **状态**：调研完成

### 🟡 问题 7：无"内部独白"机制，角色"无意识流"

- **问题代码**：全项目没有
- **症状**：
  - 真人在对话间隙会有"我刚才是不是说错话了"的反思
  - 真人在独处时会"想 ta"
  - **Lunar 的角色在两次对话之间完全静止**——没有"自我对话"
- **学术参考**：
  - Inner Speech Theory（Vygotsky）：内部语言是思维的载体
  - Default Mode Network（脑科学）：静息状态下大脑仍在活动（自我反思）
- **状态**：调研完成

### 🟡 问题 8：对"用户"无模型，角色不知道"你是谁"

- **问题代码**：`state.py` 中没有任何 UserModel
- **症状**：
  - 真人伴侣会知道"你最近工作压力大""你不喜欢香菜"
  - **Lunar 完全不知道用户是谁**——只能基于当前轮刺激反应
  - 每次对话都是"陌生人的第一次见面"
- **状态**：调研完成

### 🟢 问题 10：无"个体微习惯"，角色像"通用 AI"

- **症状**：
  - 真人会有口头禅、小动作、习惯性话题
  - Lunar 的角色每次对话行为完全由当前刺激决定，无个体辨识度
- **状态**：调研完成

### 🟢 问题 11：门控只有 3 维，心理防御"颗粒度过粗"

- **问题代码**：`state.py:170-180`
- **现有 3 维**：`G_SUPPRESSION / G_VULNERABILITY / G_ATTACHMENT`
- **学术参考**：
  - Freud/Anna Freud 的防御机制分类：压抑、投射、合理化、反向形成、升华、退化、否认、置换、认同、隔离——10 种
  - Lunar 3 维只覆盖了"压抑"和"示弱"，**其他 8 种防御完全缺失**
- **状态**：调研完成

### 🟢 问题 12：无"主观时间感"，角色"无等待焦虑"

- **症状**：
  - 真人等 1 小时觉得"等了好久"，等 1 天觉得"好久没联系"
  - 高 attachment_anxiety 的人主观等待时间更长
  - Lunar 完全无此建模
- **学术参考**：
  - 时间心理学（Psychology of Time）
  - 主观时间膨胀效应（与情绪状态正相关）
- **状态**：调研完成

### A.2 衰减机制相关（2026-06-11 讨论后立项）

| 原始问题 | 讨论结论 | 状态 |
|----------|----------|------|
| per-tick 衰减与真实时间混淆 | 需要时间戳驱动，但**不能删除**衰减本身 | 待定方案 |
| 离线 N 小时情绪仍按 per-tick 衰减 | 需引入"真实时间幂律衰减" | 待定方案 |
| 所有维度共用一套衰减常数 | 维度应有不同半衰期（irritation 快、insecurity 慢） | 待定方案 |
| 无"事件重要性"独立衰减 | 重要事件 vs 日常琐事半衰期应不同 | 待定方案 |

**讨论摘要**：
- 衰减**必要保留**（3 个不能没有的功能）：
  - "情绪余温"——LSTM 遗忘门 f_gate 需要它才有效
  - "刺激-特质共振"——高依恋焦虑者"反刍"的工程化实现
  - "2×2 防御风格矩阵"的理论基础
- 时间戳引入方向（3 种方案，待拍板）：

| 方案 | 描述 | 工作量 | 优点 | 缺点 |
|------|------|--------|------|------|
| A. 真实时间幂律衰减 | `state = baseline + (state - baseline) × exp(-λ × Δt)` | 1 天 | 简单真实 | 需每个维度存时间戳 |
| B. Per-event 时间戳 + 多时间常数 | 每个事件独立追踪半衰期 | 1 个月 | 真正"事件记忆" | 复杂度高 |
| C. 分层衰减（STM/LTM） | 短期 per-tick + 长期真实时间 | 2 周 | 兼顾两者 | 双状态向量 |

**我的偏好**：双轨制
- **短期 per-tick 衰减保留**（LSTM 3 门控 + 刺激共振用）
- **长期真实时间幂律衰减新增**（离线后的下次对话用）
- 数据结构上：每个状态维度独立存 `last_update_time`

**待解决的副作用**：
- 首次启动时间戳 = 0 导致衰减爆炸（需用 current_time 初始化）
- 测试场景下"离线时间"被算作真实时间（需支持 mock time 注入）
- 多设备/多时区不一致（建议用相对时间戳）

**学术参考**：
- Ebbinghaus 遗忘曲线（指数衰减 vs 幂律衰减之争）
- Atkinson-Shiffrin 记忆模型（感觉/短时/长时记忆分层）
- Hebbian 学习理论（高频强烈事件沉淀为长期印记）
- 情感惯性（Kuppens & Verduyn, 2017）—— 情绪反应不仅由刺激决定，还由当下状态调制
- 时间心理学（Psychology of Time）—— 主观时间与情绪状态正相关
