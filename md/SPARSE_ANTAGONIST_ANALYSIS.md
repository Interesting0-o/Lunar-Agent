## 一、问题重述

### 1.1 关系态耦合：100% 正边

```
关系态 11 条耦合边：11 正 / 0 负（100% 正）
```

关系维度之间**没有任何一条负边**。所有维度互相推高，没有自然拉低的机制。这直接导致：

- `familiarity × romantic_tension` r=+0.997
- `familiarity × dependency` r=+0.986
- `dependency × romantic_tension` r=+0.992
- 前 2 个 PC 解释 73% 方差

**原因：** 关系态 setpoint 全部为负（回避型依恋），SELF_DECAY 向 0 拉→所有维度同时上升→耦合全正边→互相推高→同步运动。

### 1.2 内部态稍好但不均衡

内部态 11 条边中 7 正 4 负（64% 正），但负边全部来自两个源：

| 源→目标 | 系数 | 含义 |
|---------|:---:|------|
| energy → stress | −0.05 | 精力→压力↓ |
| energy → loneliness | −0.05 | 精力→孤独↓ |
| social_battery → irritation | −0.08 | 电量→烦躁↓ |
| social_battery → mental_fatigue | −0.10 | 电量→疲劳↓ |

也就是说**只有 energy 和 social_battery 在输出负反馈**，其他维度全是"放大器"。

## 二、方案 A：稀疏化耦合

### 2.1 理念

耦合矩阵越密，维度间协同性越强，有效自由度越低。从**有向图**视角，每个维度的出边和入边应该是**稀疏且有语义**的，而非全面连接。

### 2.2 当前密度

| 域 | 维度 | 当前边数 | 最大可能 | 密度 |
|----|:----:|:-------:|:-------:|:----:|
| 内部态 | 8 | 11 | 56 | **20%** |
| 关系态 | 6 | 11 | 30 | **37%** |

关系态密度 37% 是内部态的 **1.85 倍**，而关系态维度更少→相对密度更高→同步效应更严重。

### 2.3 稀疏化策略

**原则：** 每个维度最多 2 条入边 + 2 条出边，且每条边必须有明确的心理学依据。

**关系态稀疏化（当前 11 条 → 7 条）：**

| 保留的边 | 系数 | 依据 |
|---------|:----:|------|
| affection → trust | 0.076 | 好感→信任（基本） |
| trust → emotional_safety | 0.094 | 信任→安全（基本） |
| emotional_safety → affection | 0.047 | 安全→好感（基本） |
| **dependency → romantic_tension** | 0.047 | 依赖→张力 |
| trust → dependency | 0.047 | 信任→依赖 |

| 移除的边 | 理由 |
|---------|------|
| affection → familiarity | familiarity 可由频次独立驱动 |
| emotional_safety → trust | 冗余（affection → trust 已有） |
| familiarity → emotional_safety | 冗余 |
| affection → romantic_tension | r=0.997 主因，改为间接路径 |
| trust → romantic_tension | 同上 |
| romantic_tension → affection | 反向，通过 B 矩阵即可 |

**内部态稀疏化（当前 11 条 → 9 条）：**

不需要大动，但可以增加 1 条负反馈：

| 改动 | 系数 | 依据 |
|------|:----:|------|
| longing → loneliness | −0.08 | **思念缓解孤独**（当前的负反馈缺失） |

### 2.4 预期效果

```python
# 关系态从完全图→最小连通图
# 依赖路径变长：affection → trust → safety → affection（环）
#            + trust → dependency → tension（链）
# 维度间同步性应显著降低
# 预期 PC1 解释方差从 ~48% → 降至 ~30-35%
# 有效自由度从 6 → 预计 7-8（14 名义维中）
```

### 2.5 风险

| 风险 | 等级 | 缓解 |
|------|:----:|------|
| 移除边后维度"失联"变死维度 | 🟡 | 确保每维至少有 1 条入边 + 1 条出边 + B 矩阵输入 |
| 环被打破后收敛变慢 | 🟢 | SELF_DECAY 兜底（ρ<1 保证收敛） |
| 现有测试数值断言失效 | 🟢 | 需重跑→更新断言 |

## 三、方案 B：引入拮抗对（负反馈维度）

### 3.1 学术基础

**对立过程理论（Solomon & Corbit, 1974）：**
每个情感状态自动触发一个方向相反的反向摆动（B-process）。现有神经生物学证据（杏仁核 ITCdm/ITCvm 互抑回路）为其提供了神经基础。

**OCC 情感模型（Ortony, Clore & Collins, 1988）：**
将情感组织为若干**拮抗对**：

| 对 | 触发条件 | 计算关系 |
|----|---------|---------|
| joy ↔ distress | 事件合意性 | 同一标量的正负端 |
| hope ↔ fear | 未来事件预期 | 互补强度 |
| pride ↔ shame | 自我行动评价 | 反向强度 |
| admiration ↔ reproach | 他人行动评价 | 反向强度 |
| love ↔ hate | 对象吸引 | 负相关 |
| gratitude ↔ anger | 他人意图 | 反向 |

**PAD 正交空间（Mehrabian, 1996）：**
Pleasure-Arousal-Dominance 三轴设计上就是近正交的（最大 r≈0.28），维度独立保证了表达力。PAD 不靠耦合矩阵推动变化，而是通过刺激直接映射到正交轴上。

### 3.2 建议新增的拮抗对

在**不增加维度**的前提下，通过**新增负耦合边**在现有维度之间创建拮抗关系：

#### 关系态（新增 5 条负边）

| 负边 | 系数 | 心理学依据 |
|------|:----:|-----------|
| dependency → trust | **−0.04** | 过度依赖→信任受损（不健康依附） |
| romantic_tension → emotional_safety | **−0.03** | 张力过高→安全感下降（心跳加速的不安感） |
| familiarity → romantic_tension | **−0.02** | 过于熟悉→浪漫感微降（熟悉导致的新奇感消退） |
| trust → dependency | **+0.05** | 信任→依赖（保留正边，但削弱） |
| emotional_safety → romantic_tension | **+0.03** | 安全→敢于动心（现有缺失） |

#### 内部态（新增 3 条负边）

| 负边 | 系数 | 心理学依据 |
|------|:----:|-----------|
| longing → loneliness | **−0.08** | 思念缓解孤独（缺失的负反馈） |
| stress → energy | **−0.06** | 长期压力消耗精力（现有缺失） |
| irritation → insecurity | **+0.06** | 烦躁后→不安（"我是不是太过分了"） |

### 3.3 引入 Pride 作为动态维度（特批新增）

当前 `pride` (T_PRIDE=1) 是 Traits（静态），但它应该是**月下角色的核心动态情感**。

**建议：** 在 InternalState 中增加 `I_PRIDE`（第 9 维），初始值从 Traits 派生，随交互动态变化。

**耦合规则：**

| 边 | 系数 | 依据 |
|----|:----:|------|
| pride → vulnerability (surface) | −0.15 | 骄傲→不露脆弱 |
| pride → sharpness (surface) | +0.10 | 骄傲→言辞锋利 |
| affection → pride | −0.03 | 好感增加→放下一丝骄傲 |
| stress → pride | +0.05 | 压力下→防御性骄傲 |
| insecurity → pride | +0.08 | 不安→伪装骄傲 |

### 3.4 预期效果

```
关系态从 11 正 0 负 → 8 正 3 负
内部态从 7 正 4 负 → 9 正 7 负

有效自由度预计：
  关系态：当前 ~2 有效 → 预计 ~4 有效
  内部态：当前 ~4 有效 → 预计 ~5-6 有效
  全系统：当前 6 有效 → 预计 9-10 有效（14 名义维中）
```

### 3.5 风险

| 风险 | 等级 | 缓解 |
|------|:----:|------|
| 负边加入可能导致振荡 | 🔴 | 需验证 ρ<0.95，必要时降低系数 |
| Pride 增加破坏现有测试 | 🔴 | 新增维度需重写所有断言 |
| 拮抗效果被 SELF_DECAY 抵消 | 🟡 | 拮抗边需大于 tax 强度 |
| 耦合图变得不对称 | 🟢 | 不对称是正常的（现实情感关系不对称） |

## 四、方案 C：A + B 合并

稀疏化 + 拮抗对同时实施，预期效果叠加但不完全线性。

```
稀疏化减密 → 维度独立基线提升
拮抗对增加 → 维度间增加反同步
两者协同 → 有效自由度最大化
```

**具体实施顺序建议：**

1. **Phase 1（效果有限）：** 内部态增加 3 条拮抗边（longing→loneliness −0.08, stress→energy −0.06, irritation→insecurity +0.06）
2. **Phase 2（不推荐）：** 关系态稀疏化 + 拮抗边——经仿真验证对有效自由度贡献 < 5%
3. **Phase 3（推荐）：** 语义合并关系维度 6→3 或重构 REL_INPUT_INFLUENCE_B——这是真正能改变维度独立性的操作
4. **Phase 4（远期）：** 双速 SSM 架构升级

## 五、真实结论（更新于 06-20 仿真验证后）

> **稀疏化+拮抗对不能解决维度冗余问题。根因是 REL_INPUT_INFLUENCE_B 矩阵的密集映射结构，而非耦合拓扑。**

对关系态全部 11 条耦合边做了系统性测试（断环、加拮抗边、强负边、组合操作），**有效自由度始终为 5/14**。甚至删除所有耦合边仅保留 B 矩阵后，冗余度反而略升（PC1 87.4%→89.2%）。

| 方案 | 有效自由度增益 | 成本 | 推荐度 |
|------|:------------:|:----:|:-----:|
| **稀疏化耦合** | ≈0%（仿真验证） | 2 天 | ❌ 无效 |
| **拮抗对（负边）** | ≈0%（仿真验证） | 3 天 | ❌ 无效 |
| **断环** | ≈0%（仿真验证） | 1 天 | ❌ 无效 |
| **语义合并 6→3** | 预计 +30-50% | 1 天 | ✅ 推荐下一步 |
| **双速 SSM** | 预计 +130% | 2 周 | ✅ 长期目标 |

- 主要冗余: expressiveness×enthusiasm(r=0.756), expressiveness×vulnerability(r=-0.703)

### 6.3 防御剖面深度分析（🔴 已修复 → 🟡 改进中）

> **2025-06-20 更新：** 全局调制已全部改为刺激特异性（每维独立权重）。本节的根因分析保留为原始记录，修复效果在 §7.3.6 总结。

#### 7.3.1 原始现象（修复前）

去激活和过度激活剖面各 7 维，但有效自由度仅 **1/7**。所有 7 个刺激维度的值 r≈1.0，独立方差 0.0%。

修复后统计（n=100,000）：

| 指标 | 去激活（修复前） | 去激活（修复后） | 过度激活（修复前） | 过度激活（修复后） |
|------|:--------------:|:--------------:|:----------------:|:----------------:|
| PC1 | 99.9% | **83.6%** | 99.4% | **92.4%** |
| 有效秩 | ~1.0 | **1.92** | ~1.0 | **1.41** |
| 95% 有效维 | 1/7 | **3/7** | 1/7 | **2/7** |
| 平均独立方差 | 0.0% | **12.6%** | 0.0% | **8.7%** |
| 维度间 max\|r\| | ~1.000 | **0.948** | ~1.000 | 0.991 |

去激活改善显著（翻倍的有效秩，PC1 下降 16 个百分点），hyper 改善较小。原因见 §7.3.6。

#### 7.3.2 根因定位（修复前，保留为历史记录）

```
deact[维度] = baseline[dim](traits)     ← 静态（trait 不变化）
            - stability*0.11            ← 共享
            - openness*0.06             ← 共享
            + avoidance*0.09            ← 共享
            * rel_loosen(trust, safety)  ← 共享乘数
            + stress*0.05 + insecurity*0.04  ← 共享加项
            → sigmoid((x-0.35)*5.0)
```

**关键发现：维度间差异化只来自第一行的 trait 基线。** 但 traits 在 Lunar 中**从不更新**（已知问题 1），因此维度间的差异是**固定偏移**，不随时间变化。所有**动态变化**来自共享调制器（rel_loosen、stress、insecurity），而这 3 个源是 7 维完全共享的。

原始方差分解（n=50,000，修复前）：

| 来源 | 去激活 | 过度激活 |
|------|:-----:|:--------:|
| 维度间差异化（动态） | **0.0%** | **0.0%** |
| 公共方差（共享调制） | 0.8% | 1.5% |
| traits 静态固定偏移 | ~99% | ~98% |

原结论：防御剖面实质性上是一个 1 维标量，伪装成了 7 维向量。

#### 7.3.3 与代码设计意图的偏差

代码注释明确写着"每个剖面是 7 维敏感度向量"，`apply_defenses` 也做了逐元素乘法 `inner = stimuli * (1.0 + hyper * 0.50)`。但在 `compute_defense_profiles` 中，维度间差异化被全局共享调制淹没。

#### 7.3.4 修复方案（2025-06-20 已完成）

将全部 13 组全局调制改为逐维度独立权重：

```python
# 修复前（共享）
deact += internal[I_STRESS] * 0.05 + internal[I_INSECURITY] * 0.04

# 修复后（逐维度独立敏感度）
STRESS_DEACT_A = np.array([0.08, 0.03, 0.01, 0.12, 0.04, 0.00, 0.08])
INSECURITY_DEACT_A = np.array([0.10, 0.05, 0.01, 0.03, 0.07, 0.00, 0.05])
deact += internal[I_STRESS] * STRESS_DEACT_A
deact += internal[I_INSECURITY] * INSECURITY_DEACT_A
```

每个调制变量（stress、insecurity、stability、trust、safety、sensitivity、avoidance、
affection、tension、longing）各有独立的 \(7,\) 权重向量，定义了该变量对 7 种刺激选择性的影响强度。

权重设计的心理学依据：
- `stress[CONFLICT] = 0.12` — 压力大最想逃避冲突
- `stress[TEASING] = 0.00` — 压力不影响调侃表达
- `trust[ABANDONMENT] = −0.14` — 信任→敢于暴露被抛弃恐惧
- `trust[CLOSENESS] = −0.08` — 对亲近的效果较弱（亲近本身不在防御范围内）
- `insecurity[ABANDONMENT] = 0.14` — 极度放大对抛弃的恐惧
- `insecurity[TEASING] = 0.00` — 不影响

完整权重表见 [`state_engine/_defenses.py`](../state_engine/_defenses.py) 模块顶层的命名常量。

#### 7.3.5 Traits 静态问题的传导效应（仍存在）

Trait 不变不仅是自身的问题——它通过防御剖面传导到整个 system：

```
Traits 静态 → 防御剖面基线偏移不变 → 状态调制虽已逐维独立
              但剖面"中心"由 traits 决定 → 仍受限于 trait 静态性
```

修复后，**动态调制**部分已具备维度特异性（stress 使 CONFLICT 的 deact 增长远快于 TEASING），但**基线偏移**（abandonment 的 deact 始终比 closeness 高 0.25）仍由 traits 决定且不随时间更新。这意味着：

- ✅ 状态驱动变化（stress↑/trust↓/insecurity↑）→ 每维响应不同
- ⏳ 基线排序（哪个刺激类型防御最强/最弱）→ 仍固定在 traits 中
- 完整解耦需要：traits → trait 演化（已列入 TODO）

**Trait 演化仍是最终解决维度冗余的两个关键杠杆之一。**

#### 7.3.6 修复后的方差分解

n=100,000 随机状态轨迹下的防御剖面方差分解（修复后）：

| 来源 | 去激活 | 过度激活 |
|------|:-----:|:--------:|
| 动态调制贡献的维度间差异 | **12.6%** | **8.7%** |
| 基线（traits）决定的静态偏移 | ~87% | ~91% |

去激活改善更大（独立方差 0%→12.6%）的原因：deact 基线本来差异小（0.15–0.30），状态调制的特异性占总方差比例更大。hyper 基线差异大（0.10–0.45），状态调制虽然也特异，但相对比例被基线淹没。

**注意：** 12.6% 和 8.7% 是独立方差均值——即该维度被其他 6 维回扣后剩余的独特方差。对去激活来说，ST_CONFLICT（21.7%）和 ST_TEASING（34.2%）的独立方差已相当可观，意味着这些维度在状态驱动下可以"自己动"，不再被其他维度拖同步。

各维独立方差明细：

|----------|:-----:|:--------:|
| ST_ABANDONMENT | 10.0% | 8.8% |
| ST_VALIDATION | 3.7% | 1.7% |

| ST_EMOTIONAL_WEIGHT | 4.5% | 0.8% |

TEASING 在两种剖面中独立方差最高，因为它受调制的刺激特性最强（stress=0.00、
insecurity=0.00、sensitivity=0.03、longing=0.02 等——大部分状态变量的
TEASING 权重接近零或很小）。这意味着 TEASING 维度几乎只由基线 + stimuli 本身驱动，
不太受当前情绪状态影响——这是符合心理学预期的（调侃作为一种社交仪式，不随内心波动剧烈变化）。

## 七、仿真验证

### 7.1 内部态 3 条拮抗边：几乎无效

在现有 pipeline 输出上叠加 3 条内部态拮抗边（longing→loneliness −0.08, stress→energy −0.06, irritation→insecurity +0.06），跑 50,000 轮 PCA 后：

| 指标 | 原始 | +3 拮抗边 | 变化 |
|------|:----:|:---------:|:----:|
| 有效维度 (95%) | **5** | **5** | 0 |
| PC1 解释方差 | 44.5% | 44.8% | +0.3% |
| 最大 |r| > 0.7 对数 | 17 | 17 | 0 |

**结论：** 内部态的拮抗边对全局冗余影响甚微。主要原因：
1. 关系态 6 维的共线性才是 PC1 的主导贡献者（关系态全部正耦合）
2. 内部态只占 14 维中的 8 维，且原有 4 条负边已提供一定拮抗
3. 耦合系数（0.05-0.06）太小，被 SELF_DECAY 和关系态同步淹没

**杠杆点清晰：关系态耦合符号改正是关键。** 只改内部态不动关系态，效果有限。

### 7.2 关系态拓扑改动的极限测试

切断 `familiarity → emotional_safety`（断开环 2）+ 添加 `tension → trust: −0.07/−0.10`（强拮抗边），结果：

| 配置 | 有效维度 | PC1 | max|r| |
|------|:-------:|:---:|:----:|
| 基线 | 5/14 | 53.0% | 0.998 |
| 切断环 2 | 5/14 | 53.9% | 0.999 |
| 切断 + tension→trust:−0.07 | 5/14 | 52.8% | 0.999 |
| 切断 + tension→trust:−0.10 | 5/14 | 53.2% | 0.999 |

**有效自由度纹丝不动。** 无论怎么改关系态耦合拓扑（切断正边、添加强拮抗边、组合操作），PCA 结果完全不变。

### 7.3 根因定位：B 矩阵，不是耦合（🚀 关键发现）

将关系态**全部 11 条耦合边删除**（仅保留 `REL_INPUT_INFLUENCE_B` 输入 + `REL_SELF_DECAY`），与全耦合基线对比：

| 指标 | 全耦合 | 零耦合 | 变化 |
|------|:-----:|:-----:|:----:|
| 关系态有效维度 | **2/6** | **2/6** | 0 |
| 关系态 PC1 | 87.4% | **89.2%** | ⚠️ 反而更高 |
| familiarity×tension | 0.998 | **0.998** | 完全相同 |
| familiarity×dependency | 0.991 | **0.999** | 几乎相同 |
| trust×safety | 0.938 | **0.989** | 零耦合更高 |

**结论：REL_INPUT_INFLUENCE_B 矩阵是维度冗余的根因，不是耦合拓扑。**

6 个关系维度从同一组 7 维刺激向量读取信号——B 矩阵的映射结构本身就决定了维度之间的高度相关。耦合只起到了"再分配"作用，不是同步运动的原因。

这也解释了之前所有尝试（加拮抗边、断环、加强负边）为何无效：**只要 B 矩阵还在以同样方式驱动所有 6 维，改变耦合拓扑无法解决同步运动。**

### 7.4 启发：真正的修复方向

```
根因链:
  同一 7 维刺激 → REL_INPUT_INFLUENCE_B 密集映射 → 6 维同步运动
  → 耦合拓扑再分配 → 维度间 r~1.0 → 有效自由度 2/6

无论怎么改耦合（稀疏化、拮抗边、断环），
只要 B 矩阵结构不变，6 维就会同步运动。
```

### 7.5 深度实验结论（06-20 第二轮）

基于 signed network theory（结构平衡）、Strogatz 爱情动力学、stimulation value 模型做了第二轮更严谨的实验：

**① 结构平衡（Structural Balance，来自 signed graph theory）：**

加入 `familiarity→tension: −0.07` 会在 `aff→fam→tens→aff` 环中创建奇数个负边 → 系统呈 frustration。修复方法：同时将 `tension→affection: +0.028` 翻转为 `−0.028`（偶数负边，结构平衡）。但即使修复：

| 配置 | 有效维度 | PC1 | max|r| |
|------|:-------:|:---:|:----:|
| 基线 | 2/6 | 87.4% | 0.998 |
| 单拮抗（非平衡） | 2/6 | 87.4% | 0.998 |
| 结构平衡 | 2/6 | 88.4% | 0.998 |
| 结构平衡+删边 | 2/6 | 88.4% | 0.998 |

**结构平衡不影响有效自由度。** 但改善了系统的可预测性（减少初始条件敏感性）。

**② 零线分析（Nullcline）：拮抗边确实改变了动力学行为**

零刺激下扫描 familiarity 水平，测 tension 平衡点：

```
基线:      d(tension)/d(fam) ≈ +0.009  → 接近平线
fam→tens: d(tension)/d(fam) ≈ −0.244  → 清晰负相关！
```

**效果：** 高熟悉度 → 张力被抑制。这验证了 Berscheid stimulation value 模型——熟悉度消耗暧昧感。**但这是线性斜率变化，不是相变。**

**③ 双稳检测：无真实相变**

从 ±0.8 的不同张力初始值出发，经 2000 轮收敛到同一平衡点（展宽 < 0.015）。线性系统无法产生分叉（bifurcation）。要产生真正的"暧昧→稳定"相变需要：
- 非线性耦合（如二次项，类似 Strogatz love dynamics 扩展版）
- 或阈值触发机制
- 或正反馈环（临界慢化 → 相变）

**④ 终极根因：耦合 vs B 矩阵的力量比**

```
α × 耦合系数 ≈ 0.045 × 0.047 = 0.0021/轮
β × B矩阵系数 ≈ 0.040 × 0.08  = 0.0032/轮
```
但 β × B 矩阵总输入涉及 7 维 × 6 映射 = 42 条路径，总驱动力是耦合的 **5-10 倍**。

```
结论: 耦合是 B 矩阵的"精细调制"，不是主导驱动力。
      拓扑改动（稀疏化/拮抗/断环）无论多精妙，
      都无法战胜 B 矩阵的结构性支配。
```

| 真正有效的方案 | 原理 | 成本 |
|-------------|------|:----:|
| **语义合并关系维度**（6→3） | 减少接受同一 B 矩阵映射的输出维数 | 低 |
| **重构 REL_INPUT_INFLUENCE_B**（每个关系维去相关化） | 改变刺激→维度的映射模式 | 中 |
| **双速 SSM**（PAD 正交基底） | 用近正交的 PAD 3 维替代耦合驱动的扁平空间 | 高 |
